# The Mumfali Story

A private interactive birthday scrapbook built with React, Vite, JavaScript, CSS, and Framer Motion.

## Local Preview

```bash
npm install
npm run dev
```

The app is designed mobile-first for Android viewing.

## Project Structure

- `src/components/` reusable UI and motion components
- `src/sections/` cinematic story sections
- `src/data/` editable copy and future story data
- `public/photos/` private photos or screenshots when you are ready to add them

## GitHub Pages

The workflow in `../.github/workflows/deploy.yml` installs dependencies, builds the Vite app, and publishes `surprise-site/dist`.
